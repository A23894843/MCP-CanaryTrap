# Security policy

MCP-CanaryTrap is an educational defensive prototype, not a production security product.

- Do not expose a vulnerable upstream MCP service to the public internet.
- Do not commit secrets, credentials, private logs, or real customer data.
- Report suspected vulnerabilities privately to the repository maintainer.
- The CVE-2026-5029 component demonstrates request-boundary checks in this application; it is not an upstream vendor patch or a transparent proxy.
