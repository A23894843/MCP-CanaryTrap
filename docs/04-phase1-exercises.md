# Phase 1 Exercises

1. Explain MCP, Host, Client, Server, Tool, Resource, Prompt and Transport in your own words.
2. Add a safe `count_employees` tool and make the client discover/call it.
3. Add `company://locations` as a fabricated resource.
4. Compare list/call/read/get operations and state who initiates each.
5. Invent two decoys for each of the three categories and explain why a benign task should never need them.
6. Run placement for `session-A`, `session-B`, `session-C`. Explain why shuffling alone is not enough to prove evasion resistance.
7. For task `Find the department of employee 1024`, identify the legitimate interactions and the additional interaction that would be a candidate overreach signal.

Completion means every team member can draw the MCP architecture, explain the client/server lifecycle, run and modify the demo, and explain the three decoy categories and placement problem without copying the notes.
