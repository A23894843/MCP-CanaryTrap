Why this is useful

The unique feature is the Canary Evidence Ledger: decoy detections and CVE gateway decisions produce a hash-linked record trail. It helps an examiner or security operator detect accidental or unauthorized changes to the stored evidence. It is tamper-evident, not tamper-proof; production deployments should periodically anchor the head hash in an external immutable store.
