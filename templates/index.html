What problem does it solve?

MCP servers can expose tools and resources to AI clients. If a client or agent probes a decoy tool such as system_secrets, the application flags the interaction and records an audit event. A separate CVE demonstration endpoint shows how an exposed MCP request boundary can require authentication and trusted request metadata.

Scope: this is a defensive academic prototype. The CVE module demonstrates gateway checks; it is not a vendor patch and does not claim to secure an upstream Code Runner instance unless deployed as its actual network gateway.
